# Python Task Manager

A simple command-line task manager built with Python.

## Features

- Add tasks
- View tasks
- Delete tasks
- Exit the application

## Technologies

- Python
- Git
- GitHub
- GitHub Actions

## Example
When you run the application, you will see:

1. Add Task
2. View Tasks
3. Delete Task
4. Exit

The application runs directly in the terminal and does not require
any external Python packages.
